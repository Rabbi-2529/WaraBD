Meet the FT-SCL029

A smart lock that fits where keys never worked well

The keypad sits flush on the outside of the door while a motorized lock body mounts out of sight inside. Owners keep a management code and USB keys; everyday users get their own code — or, in public mode, every visitor sets a fresh one.

  • Fits doors thicker than 3 mm — cabinets, drawers, wardrobes, lockers

  • Minimalist black ABS body that suits any furniture

Two ways to use it

Public mode or private mode — you choose

Switch the lock between shared, visitor-friendly use and fixed personal access.

Public mode Visitor password

  • Each visitor sets their own code when locking
  • The code is released after they unlock
  • No codes passed between strangers
  • Management code & USB key can always override

Best for: gyms, spas, hotels, schools, malls

Private mode Fixed code

  • One fixed user code for everyday access
  • Separate management code for the owner
  • 1 main + 3 management USB keys as backup
  • Ideal for personal and staff storage

Best for: homes, offices, clinics, shops

Simple setup

Up and running in four steps

No electrician, no wiring — just basic tools and a few minutes.

Mount it

Fix the round keypad on the front and screw the lock body inside the door (3 mm+ thickness).

Set your codes

Create a management code for the owner and a user code for daily access.

Pick a mode

Choose public mode for visitors or private mode for a fixed personal code.

Tap & open

Enter the code and the motor unlocks. USB keys and USB power are your backup.
